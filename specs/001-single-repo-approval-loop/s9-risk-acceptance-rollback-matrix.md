# S9 风险、验收与回滚矩阵

**日期**：2026-10-24　**状态**：DRAFT（待审批）

## 1. 风险矩阵

| 风险 | 影响 | 缓解 | 残余 |
|---|---|---|---|
| 独立账户令牌未真正替换（TokenUser 仍是宿主） | 身份隔离失效 | Launcher 用 LogonUserW 验证 TokenUser；挂起创建后复核 | 需实机验证 |
| 挂起创建后 Job 纳管失败遗留进程 | 逃逸/僵尸进程 | job.assign 失败补 terminate+等待 | 需异常注入测试 |
| 出口被当作通用代理 | 任意出站 | 出口仅固定 Messages POST，无 CONNECT/SOCKS | 需渗透验证 |
| DNS/回环/服务代发绕过 | 网络隔离失效 | 默认拒绝 + 全覆盖分析 + 拒绝观测 | 有限探测不足，需策略覆盖分析 |
| 摘要与请求体不同步 | 审计失实 | request_digest 与不可变字节直接绑定，发送前复核 | 需篡改负向测试 |
| 收据重放/跨任务替换 | 证据伪造 | attempt_id 全局唯一 + 一次性收据 | 需重放测试 |
| 凭据泄露 | 安全事故 | 仅环境注入、日志脱敏、受保护凭据存储 | 需 canary 测试 |
| 部署宿主资源不足 | 部署失败 | 独立主机/云 VM；本机 NO-GO | 需选型确认 |

## 2. 验收矩阵（分阶段，见 phased-tasks）

| 阶段 | 验收标准 |
|---|---|
| S9-1 身份 | TokenUser 匹配批准 SID；挂起创建+复核+Job 纳管+进程树回收 |
| S9-2 绑定 | 摘要篡改/收据重放/跨任务替换被拒；attempt/authorization/receiver/request_digest 一致 |
| S9-3 网络 | 非授权目的地拒绝观测；授权通道可达；无任意转发 |
| S9-4 证据 | 缺发送前证据零外发；发送后收据/原始响应摘要/唯一终态齐全 |
| S9-5 实机 | 实机矩阵全量；回滚演练通过 |

## 3. 回滚矩阵

| 场景 | 回滚步骤 |
|---|---|
| 发送入口关闭 | 停用生成接口，阻断新发送 |
| 进程回收 | 终止并等待 Worker 树退出，再清理任务资源 |
| 网络断开 | 断开专用网络，停止 egress relay |
| 证据保存 | 保存审计与收据后，再撤销自建资源 |
| 资源撤销 | 按部署清单精确对象 ID 删除；不用宽泛通配符；不撤销 Codex/其他应用资源 |

## 4. 需人工批准的操作清单

1. 部署宿主选定（本机升级 / 独立主机 / 云 VM）。
2. VM/网络/出口创建、账户与登录权、启动器安装、专用 ACL/策略/审计、凭据注入。
3. 真实 OS 验收（进程树、身份、目录拒绝、v4/v6/回环/代理/服务代发拒绝、允许出口、策略变更失效）。
4. 首次真实百炼调用（合成业务内容）——单独授权。
