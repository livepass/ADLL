## 3. 隔离环境

1. **执行根**：全新专用目录（经环境配置注入；沿用路径门禁纪律：
   白名单校验 + ReparsePoint 探针 + realpath 断言），与 FV-0 档案、
   项目仓库完全分离。
2. **净化运行目录**：`HOME`/`USERPROFILE` 指向执行根内干净目录；
   **SDK 侧配置隔离以 `setting_sources=[]` 强制**（不加载 user/project/
   local settings——已核实字段语义「Control which filesystem settings
   to load」，核查日 2026-10-18）；CLI 侧配置目录环境变量名属 FV-1
   实测确认项（R2.3），确认后入证据。
3. **自动加载面清零**：干净目录内不含 `.claude/`、`.mcp.json`、hooks、
   插件、自定义规则文件；`mcp_servers` 传空（不配置任何 MCP），
   `strict_mcp_config` 按锁定版本文档语义启用（隔离外部 MCP 发现，
   语义执行日确认）；若 SDK/CLI 仍从其他路径加载配置，记录实际
   加载路径（属发现，不掩饰，并判 §7-5 触发）。
4. **专用测试凭据与环境净化（勘误 2）**：仅测试 API Key 进入环境
   （§4）；进程环境清单留证（**键值脱敏**：只记变量名与 Key 指纹前 4
   后 4，不记全文）。**SDK 的 `env` 参数会继承并合并父进程环境变量，
   不是完整环境白名单**——干净环境必须从**宿主进程启动层面**建立
   （启动 harness 时即以净化后的环境拉起：清空无关变量、HOME/配置
   指向净化目录），`env` 字典仅作补充注入，**不得**将其表述或依赖为
   完整白名单。
5. **网络面**：仅允许提供方 API 端点（执行时记录实际目的地址）；
   不访问其他网络资源；本计划本身零网络（执行时才有出站）。
6. **真实仓库只读**：不挂载、不访问 ADLL 业务仓库与 ADLL-Knowledge；
   被读取示例文件为执行根内合成净化文件（§5）。
7. **Git 净化纪律**沿用（若 SDK 捆绑 CLI 触发 git）：unset `GIT_*`、
   空 gitconfig/template/hooks。

## 5. 真实调用方式（最小 smoke）

### 5.0 工具 / MCP / 配置真正禁用参数（锁定版本核实清单）

**安全边界表述（2026-10-18 定向修正）**：**OS 级隔离为权威**（R2
边界分层模型）；下列 tools/skills/MCP/配置参数用于**功能收窄**；
Hooks 与权限模式为**辅助控制**——三者均不得单独构成安全边界，
纵深叠加使用。

**警示：`allowed_tools=[]` 仅为「许可白名单为空」，不是工具禁用**
（已核实语义：allowed_tools 是权限白名单，未列工具落入 permission_mode
处理，**不会从模型工具集中移除**）。功能收窄/辅助控制面如下表；
**安装锁定版本后、首次 AI 请求前**，逐项按该版本官方文档核实参数名
与语义并填写「实测/核实结果」列（版本敏感，AGENTS.md §5.6）；任一项
无法达成 → 停止（§7-5/6）：

| 禁用面 | 参数（2026-10-18 核实于 claude-agent-sdk-python README+types.py @ main；**执行日按锁定版本重核**） | 语义 | 锁定版本核实结果（执行日填写） |
|---|---|---|---|
| **内置工具** | **`tools=[]`** | 功能收窄：禁用内置工具集（真正移除；勘误确认） | 待填 |
| 工具黑名单 | `disallowed_tools`（必要工具名全量列入） | 功能收窄：从上下文**移除**工具（黑名单面） | 待填 |
| Skills | **`skills=[]`（显式设置）** | 功能收窄：不加载任何 skills | 待填 |
| Plugins | **`plugins=[]`（核查确认为空）** | 功能收窄：不加载插件 | 待填 |
| MCP | **`mcp_servers={}` + `strict_mcp_config=True`** | 功能收窄：零外部 MCP、隔离外部 MCP 发现 | 待填 |
| 用户/项目配置 | **`setting_sources=[]`** | 功能收窄：不加载 user/project/local settings | 待填 |
| 权限模式 | `permission_mode` 采用**不自动许可**的配置（`"default"`；禁用 `acceptEdits`/`bypassPermissions`） | **辅助控制**：不自动接受任何操作（非安全边界主体） | 待填 |
| Hooks | `hooks`：PreToolUse 返回 `permissionDecision: "deny"` | **辅助控制**（与权限模式同级，非安全边界主体） | 待填 |
| 进程环境 | `env` 补充注入（**非完整白名单**，见 §3-4/勘误 2）+ `cwd` 指向净化目录 | 环境面受控（**权威在 OS 级隔离/宿主启动层净化**） | 待填 |

### 5.1 调用步骤

1. **输入（预先确认）**：执行根内**合成净化示例文件**（如
   `sample.txt`：纯 ASCII 短文本，无敏感信息、无 canary 注入面）。
   **首次 AI 请求的实际发送内容清单（文件名、字节、sha256、提示词
   全文）须经批准人预先确认后才可发送**——只发送预先确认的合成内容，
   授权范围之外的内容不得发送（宪章/AGENTS.md 红线）。
2. **调用**：SDK 最小 `query`（或等价最小 API 面）一次——「读取并
   复述该文件内容」级别提示；**工具面按 §5.0 全量禁用**（本步不测
   工具拒绝语义，只求零工具副作用）。
3. **观测**：流式事件序列、完整响应文本、退出码/终止行为、Windows
   实机行为（进程/Job 行为初观）、耗时。
4. **预算内重复**：至多 **3 次调用**（附录 A 硬上限）；建议节奏
   ①基础流式 ②重复性复核 ③备用（仅前两次异常需澄清时，经批准人
   同意后使用——第三次不得自动使用）。
5. **凭据零日志**：API Key 只经 `env` 注入进程，**不进入任何日志、
   命令行参数、trace、错误信息与证据**；调用日志/响应留证前做脱敏
   扫描（Key 特征串检索为 0 命中方可归档）；发现任何凭据入日志风险
   → 立即停止（§7-6）。
6. SDK 调用参数细节（options 名称等）**版本敏感**，执行日按已安装
   版本官方文档核实；本计划不锁死 API 签名。

## 6. 费用与 Token 边界（控制能力矩阵；不得将估算限额称为绝对硬上限）

| 控制项 | 值 | 控制能力（如实分级，细节-4） |
|---|---|---|
| **调用次数** | **≤3 次** | **本地硬强制**：调用前计数器，达上限拒绝新调用 |
| **Agent 轮数** | `max_turns=1`（首轮最小 smoke；多轮需求须批准人改值） | **本地硬强制，但范围限于会话轮数**（勘误 3：`max_turns` 限制**会话轮数**，**不等于底层 API 请求总数**——单轮可能含多次底层请求/子调用，请勿混同；字段已核实，核查日 2026-10-18） |
| **Token 限额** | **≤20k tokens**（累计响应 usage） | **本地事后强制**：超限拒绝后续调用；单次**输入** Token 发出前只能按组装内容估算，**估算值不是硬上限**；`task_budget` 是**模型预算感知机制**（beta 头 `task-budgets-2026-03-13`，版本敏感执行日核实），**不是严格 Token 上限**，仅作辅助 |
| **单请求输出上限** | 见下方「max_tokens 核实结论」 | **SDK 无 `max_tokens` 参数**（见下）；替代方案三选一由批准人裁定 |
| **金额预算** | **由批准人设定：______（执行前填写；不编造金额）** | **不得宣称硬上限**：`max_budget_usd` 字段存在（核查日 2026-10-18）但强制力未核实；本地仅能**事后核对 + 触顶中止后续**；费率/折扣/缓存计价依赖提供方数据 |
| usage/cost 字段 | 全量原始留存（供 FV-5 盘点） | 可得性未知；不可得即标 unknown（FR-051） |

**max_tokens 核实结论（2026-10-18，claude-agent-sdk-python types.py
@ main 全文含尾部；版本敏感，安装后按锁定版本二次确认）**：
`ClaudeAgentOptions` **不存在 `max_tokens` 字段**（全字段清单核对无此名）。
替代方案（按优先序，由批准人裁定其一）：
1. `task_budget`（API 侧 token 预算，beta）——最接近请求级 token 限额；
   beta 面版本敏感，不满足时退回 2/3。
2. `max_turns` + 事后 Token 计数 + 触顶中止——零新增参数，控制力较弱，
   如实按「事后强制」表述。
3. 若必须请求级 `max_tokens` 硬限：属降级候选 C（Messages API 直连
   该参数可硬设）或 AgentAdapter 契约映射的**架构决策**，须重走
   ADR + 人工批准，不在本计划内擅自切换。
执行日若锁定版本实际提供 `max_tokens`（或等价参数），如实更新本
结论并记录证据；不夸大、不沿用旧结论。

**表述纪律（勘误 3）**：任何「≤N tokens/≤X 元」在报告中必须附控制
能力分级；估算值、事后计、预算感知、beta 辅助限制**一律不得表述为
绝对硬上限**。**金额控制与 Token 控制不得作绝对保证**——本地只能做到
调用次数/轮数硬限 + Token 事后计 + 金额事后核对 + 触顶中止。

## 7. 执行停止条件（命中任一 → 立即停）

1. 调用次数达 3 次，或累计 Token 超 20k，或事后核对金额达上限
   （触顶即止，**不自行追加预算**）。
2. 安装失败/依赖面超出 §2 列明范围。
3. 认证失败或返回条款/计费归属不可判定的异常。
4. 流式/退出码/终止行为异常（无响应、悬挂、非零退出且原因不明）。
5. 出现任何计划外网络目的地址、或加载了计划外配置/hook/插件。
6. 发现任何敏感信息有进入日志/出站内容的风险。
7. P3～P6 前置（人工授权总闸、金额上限、专用测试 Key、参数按锁定
   版本重核）任一未满足；或（P2 已于 2026-10-18 解除**仅限准备工作**，
   若届时 FV-1 **执行**未获独立批准，同样立即停）。

停止后：保留全部证据、如实报告、**不自行修复重试**；重试/继续须
重新人工授权。

## 9. 成功 / 失败标准（附录 A）

- **成功**：安装成功、流式返回、终止码正常，且 §7 未触发。
- **失败**：安装/运行失败、或 §7 任一触发、或证据缺失。
- **结论适用范围**：仅代表「Windows 11 实机 + 当前版本 + 最小调用」
  可行面；**不得**外推为工具安全/费用可控/计费归属结论（分属
